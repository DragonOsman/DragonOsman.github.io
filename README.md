## Overview

This portfolio provides an overview of my work and interests in web development. It serves as a central place to explore my projects, learn about my technical skills, and find ways to contact me.

## Features

- **About:** An introduction to my background and interests.
- **Projects:** A showcase of selected development projects.
- **Contact:** Information and links for getting in touch.
- **Responsive design:** A layout intended to work across different screen sizes.
- **Maintainable code:** Organized frontend code with consistent styling and linting.

## Technology Stack

- **HTML5:** Page structure and semantic markup.
- **JavaScript:** Client-side functionality and interactivity.
- **Sass:** Stylesheets, reusable styling patterns, and CSS organization.
- **ESLint:** JavaScript code analysis and consistent coding practices.
- **GitHub Pages:** Hosting the live portfolio website.
